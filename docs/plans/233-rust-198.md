# Issue #233: Raise the stable Rust baseline to 1.98

Resolves #233.

## Overview

Pin stable Rust 1.98.1 and declare MSRV 1.98 consistently. Preserve existing
sample processing while adopting fixed-size slice groups required by the new
compiler's default Clippy lint. This independent project-wide prerequisite blocks
#226 and PR #232; it does not change their toolkit graph or reopen their reviews.

## Roles and risk

- Class: A, because fixed-group iteration crosses DSP, sample conversion and saving.
- Coordinator: `gpt-6-astra` medium.
- Executor: `gpt-6.1-sol` medium.
- Reviewer: `gpt-6.1-sol` high in a separate agent and context.

## Context

PR #232 macOS [CI job](https://github.com/o-kos/argand/actions/runs/42649667191/job/129272466192)
fails with E0658: gpui-pre-macos 0.3.12 uses `Option::map_or_default` under Rust
1.97.1. The [official Rust source](https://github.com/rust-lang/rust/blob/1.98.1/library/core/src/option.rs#L1296)
marks that API stable since 1.98.0. A minimal probe fails on 1.97.1 and compiles
and runs on stable 1.98.1. No compatible newer backend is published within the
facade's exact dependency selection.

A warning-only survey of the migration branch found 37 fixed-size
`chunks_exact_to_as_chunks` sites: 11 production iterations in DSP STFT, I/O
conversion and float writing, and app RGBA conversion, plus 26 test iterations.
Refresh the inventory on this branch's main base before editing; its count may
differ. Read the routed processing, editing/I/O and analysis/rendering contracts.

## Decisions

- Use stable Rust 1.98.1, workspace MSRV 1.98 and matching README badge/link.
- Replace only flagged fixed-size `chunks_exact(N)` iteration with complete-array
  iteration through `as_chunks::<N>().0`. Preserve dropped remainders, element
  order, zip truncation, numerical expressions and bounds. Keep dynamic chunking
  and unflagged `chunks_exact_mut` unchanged.
- Keep source stamps, staged publication, buffer bounds and cancellation intact.
  Do not change runtime scheduling, textures, toolkit dependencies or Cargo.lock.
- Test incomplete tails with independent expected sample values and counts,
  including widths 2, 3 and 4 and odd I/Q scalar tails where reachable. Extend
  existing focused test files; do not reorganize production modules or relocate
  unrelated existing tests.
- This is a separate compiler compatibility task with its own independent review
  rounds. Review must assess exact chunk semantics, numerics and source safety.
- No lint suppressions, registry patches, nightly compiler or product changes.

## Rejected alternatives

- A four-file pin-only correction leaves strict Clippy failing across the project.
- Adding these broad code changes to the already reviewed UI migration obscures
  scope and compiler compatibility review.
- Relaxing warnings or patching toolkit sources avoids the supported stable API
  baseline and weakens the gate.
